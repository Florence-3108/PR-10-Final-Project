Global Happiness Report Analysis 🌍

📌 Project Description

This project analyzes the Global Happiness Report 2024 using Python. It explores happiness scores across different countries and studies the relationship between happiness and factors such as GDP per capita, social support, healthy life expectancy, freedom, generosity, and corruption.

The project uses data analysis and visualization techniques to understand global happiness levels.

🎯 Objectives

- Analyze global happiness scores.
- Identify the top 10 happiest countries.
- Identify the 10 least happy countries.
- Calculate the average happiness score.
- Find missing values and display statistical summaries.
- Study the relationship between happiness and other factors.
- Visualize data using different graphs.

🛠️ Technologies Used

- Python – Programming language
- Pandas – Data loading, cleaning, and analysis
- Matplotlib – Data visualization
- Seaborn – Statistical graphs and visualizations

📂 Dataset

Dataset Name: Happiness Report 2024

File Name: "happiness-report-2024.csv"

The dataset contains country-wise happiness scores and related factors, including:

- Country Name
- Ladder Score
- Log GDP per Capita
- Social Support
- Healthy Life Expectancy
- Freedom to Make Life Choices
- Generosity
- Perceptions of Corruption

📊 Features

1. Displays the first five rows of the dataset.
2. Shows dataset information and dimensions.
3. Checks and handles missing values.
4. Generates a statistical summary.
5. Displays the top 10 happiest countries.
6. Displays the 10 least happy countries.
7. Calculates the average happiness score.
8. Creates visualizations:
   - Bar Chart – Top 10 Happiest Countries
   - Regression Plot – Social Support vs Happiness
   - Density Plot – Social Support vs Happiness
   - Hexbin Plot – Healthy Life Expectancy vs Happiness
   - Heatmap – Correlation Between Happiness Factors

⚙️ Installation

Install the required libraries using:

pip install pandas matplotlib seaborn

▶️ How to Run

1. Download or clone this repository.
2. Place "happiness-report-2024.csv" in the same folder as the Python program.
3. Install the required libraries.
4. Run the Python file:

python happiness_analysis.py

5. View the analysis results in the terminal and the graphs in separate windows.

📈 Expected Output

- Dataset information and statistical summary.
- Top 10 and bottom 10 countries by happiness score.
- Average global happiness score.
- Five graphical visualizations showing happiness trends and relationships.
- Final analysis results, including the happiest country and its happiness score.

📝 Conclusion

This project helps understand how happiness differs across countries and how economic, social, and health-related factors are associated with happiness. The visualizations make it easier to identify patterns and correlations in the data.
